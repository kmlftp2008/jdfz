## Install

Use the Skills CLI to install a skill from its upstream repository, for example:

```bash
npx skills add vercel-labs/skills --skill find-skills -g -a codex -y
```

Repeat with the upstream repository and skill name shown above.

## Note

This repository is a curated index, not a complete mirror of the upstream projects. Some skills rely on additional reference files or tools maintained by their upstream repositories.
